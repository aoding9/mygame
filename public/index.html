筛选

添加用户

在 Edge 登录 Steam 后，点「获取 Token」全选复制整页 JSON 粘贴即可，会自动提取 webapi_token

编辑用户

留空则不修改 Key；勾选下方可清除已保存的 Key。

连接 Epic

可先尝试邮箱密码登录。Epic 常会要求人机验证（captcha），若密码登录失败，请展开下方「浏览器授权码」完成连接。刷新游戏库时会优先读取本机 Epic Launcher 数据。

浏览器授权码（密码登录遇到 captcha 时使用）

1. 在浏览器打开 Epic 登录并获取授权码（需先登录 Epic 账号）。
2. 在浏览器里全选复制整段 JSON 粘贴到下方，会自动解析 authorizationCode 并连接（约 5 分钟有效）。

连接育碧

使用 Ubisoft 账号邮箱和密码登录。若开启双重验证，提交密码后会显示验证码输入框。本机已登录 Ubisoft Connect 时，刷新会自动读取本地游戏库。

编辑游戏资料

从 Steam 客户端导入隐藏

将读取本机 Steam 配置中的「已隐藏」分类，并合并到当前用户的隐藏列表（不会覆盖你手动隐藏的游戏）。
